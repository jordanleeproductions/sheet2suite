# Sheet2Suite & Sheet2Vow Brand Assets Drop Folder

Save your exported Canva assets here using the standard naming conventions below.

## Recommended File Names

### 1. Sheet2Suite (Parent Platform)
- `sheet2suite-logo.png` — Horizontal wordmark logo (Dark text, `1600 × 400 px`, transparent background). Used for light navbar headers and invoices.
- `sheet2suite-logo-white.png` — Horizontal wordmark logo (White text, `1600 × 400 px`, transparent background). Used for dark headers and mobile drawers.
- `sheet2suite-icon.png` — Master square icon (`1024 × 1024 px`, transparent background).
- `sheet2suite-icon-solid.png` — Master square icon on solid background (`1024 × 1024 px`). Used for PWA and Apple touch icons.

### 2. Sheet2Vow (Wedding Planning Suite)
- `sheet2vow-logo.png` — Horizontal wordmark logo (Dark text, `1600 × 400 px`, transparent background). Used for app sidebar header.
- `sheet2vow-logo-white.png` — Horizontal wordmark logo (White text, `1600 × 400 px`, transparent background). Used for dark sidebar mode.
- `sheet2vow-icon.png` — Master square icon (`1024 × 1024 px`, transparent background). Used for collapsed sidebar icon.
- `sheet2vow-icon-solid.png` — Master square icon on solid background (`1024 × 1024 px`).

### 3. Social / Open Graph Preview Cards
- `sheet2suite-og.png` — Open Graph preview banner (`1200 × 630 px`).
- `sheet2vow-og.png` — Open Graph preview banner (`1200 × 630 px`).

---

## Canva Export Settings Checklist:
1. **File Type:** `PNG`
2. **Transparent background:** Checked (`ON`) ✅ (except for solid app icons)
3. **Size:** `1x` (since master canvas is already high-density)
